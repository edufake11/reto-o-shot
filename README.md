# Reto o Shot

Juego de retos para adultos (+18) en una sola página HTML.

- Añade los nombres de los jugadores en el orden en que están sentados.
- Elige nivel: Suave, Picante, Atrevido o Extremo (40 retos cada uno).
- En cada turno: cumple el reto o pulsa **¡Shot!** para pasar.
- Algunos retos los decide el jugador de la derecha; otros eligen a alguien al azar.
- Marcador de retos cumplidos y shots por jugador.

Abre `index.html` en el navegador para jugar. Antes de empezar, que cada uno diga sus límites.
